# Fonctionnalités — Capybara CMDB Community

Capybara CMDB Community est une **édition unique et gratuite** : tous les modules ci-dessous sont inclus dès l'installation, sans palier ni clé de licence.

## Inventaire & cartographie

- Inventaire matériel (serveurs, postes, réseau) et logiciel
- Cartographie des dépendances entre CIs (graphe interactif)
- Segments réseau, VLAN/DMZ
- Recherche globale (`Ctrl+K`)
- Tableau de bord et dashboard exécutif (score de gouvernance)

## ITSM

- Gestion des incidents (timeline, lien ticket externe)
- Demandes de changement (RFC)
- Contrats SLA (suivi, expiration, couverture)
- Gestion des licences logicielles (sièges, expiration, conformité)
- Calendrier de maintenances (+ synchronisation Outlook/M365 en option)

## Connecteurs & intégrations

- LDAP / Active Directory
- Microsoft EntraID / Intune
- GLPI
- SSO / SAML 2.0 (Okta, ADFS, etc.)
- Webhooks sortants
- Tokens API (accès machine-to-machine)
- Réception SNMP/webhook → création d'incidents automatique

## Agents natifs

- Agent léger Windows / Linux / macOS pour la remontée automatique d'inventaire
- Scripts d'installation prêts à l'emploi (`agents/`), y compris un wrapper Intune

## Sécurité & conformité

- Authentification JWT, LDAP, SSO/SAML, TOTP
- Rôles et permissions fines par module
- Journal d'audit complet
- Veille CVE réactive (NVD, CISA KEV, OSV)
- Qualité des données (détection de CIs incomplets, doublons, anomalies)

## Rapports & notifications

- Export de rapports PDF / CSV
- Notifications email sur événements CMDB
- Sauvegardes planifiées

## Personnalisation

- Nom de l'application, couleurs, logo personnalisables (Admin > Personnalisation)
- Image de fond de la page de connexion
